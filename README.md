# 🚗 Калькулятор авто из-за рубежа — Telegram Mini App

Telegram Mini App для расчёта полной стоимости авто «под ключ» при ввозе в РФ
из 🇯🇵 **Японии**, 🇰🇷 **Кореи** и 🇨🇳 **Китая** (включая **электрокары**).

Перенос логики из Google-таблицы «КАЛЬКУЛЯТОР АВТО» в удобное приложение.

## Что умеет

- **3 страны + электрокары**, разные валюты (¥ JPY, ₩ KRW, ¥ CNY) и схемы оплаты.
- **Пошлина** по официальным правилам ЕТС:
  - до 3 лет — `max(% от стоимости, €/см³)`;
  - 3–5 / 5–7 / старше 7 лет — ставка €/см³;
  - электрокар — пошлина 15% + акциз + НДС 20%.
- **Утильсбор** = базовая ставка × коэффициент (объём + мощность + возраст), включая ставки 2026 для EV.
- **Таможенный сбор** за оформление по таможенной стоимости.
- **Расходы по РФ** (брокер, СБКТС/ЭПТС, СВХ, лаборатория, вывоз) — пресеты по странам, всё редактируется.
- **Курсы валют**: ЦБ РФ тянутся автоматически (`cbr-xml-daily.ru`), рыночные и ставки правятся в настройках ⚙️.
- **~180 аукционов Японии** с FOB-прайсами (доставка + фрахт) — выбор из списка.
- Полная разбивка расчёта + **этапы оплаты**.

## Структура

```
index.html        — разметка Mini App
css/style.css     — оформление (нативная тема Telegram)
js/data.js        — справочные данные (таблицы пошлин, утиля, акциза, аукционы, пресеты)
js/calc.js        — движок расчёта
js/rates.js       — загрузка курсов ЦБ + хранение ручных правок (localStorage)
js/app.js         — интерфейс и интеграция с Telegram
bot/bot.js        — бот, открывающий Mini App
```

## Как запустить

### 1. Разместить Mini App (фронтенд)

Mini App — это статический сайт по HTTPS. Самый простой бесплатный вариант — **GitHub Pages**:

1. Создайте репозиторий и залейте туда содержимое этой папки (кроме `bot/`).
2. Settings → Pages → Source: `main`, папка `/root`.
3. Получите адрес вида `https://username.github.io/repo/`.

Локальная проверка в браузере:
```bash
cd "Calculate-App-TG"
python3 -m http.server 8080
# открыть http://localhost:8080
```

### 2. Создать бота и привязать Mini App

1. У [@BotFather](https://t.me/BotFather): `/newbot` → получите `BOT_TOKEN`.
2. `/newapp` (или `/myapps`) → привяжите URL вашего Mini App.
3. Можно сразу задать кнопку-меню: `/setmenubutton` → URL приложения.

### 3. Запустить бота

```bash
cd bot
cp .env.example .env      # впишите BOT_TOKEN и WEBAPP_URL
npm install
npm start
```

Бот по `/start` пришлёт кнопку «Открыть калькулятор». Кнопка-меню слева от поля ввода
тоже откроет приложение.

> Бот должен работать постоянно. Бесплатные хостинги: Railway, Render, Fly.io, или любой VPS.
> Если нужен только Mini App без чат-бота — можно открывать приложение прямо по кнопке-меню,
> настроенной в @BotFather, и бота не запускать.

## Настройка под себя

Откройте ⚙️ в приложении:
- **Курсы ЦБ** — кнопка «Обновить» тянет актуальные; можно поправить вручную.
- **Рыночные курсы** — по ним считается реальный платёж за авто (USDT/RUB, ¥ за 100, CNY и т.д.).
- **Расходы по РФ и комиссия** — правятся прямо на главном экране для каждой страны.

Все правки сохраняются **на устройстве** (localStorage). Чтобы настройки были общими
для всех пользователей — нужен бэкенд с хранением (можно добавить позже: эндпоинт
`/api/config`, отдающий JSON, который читает `js/rates.js`).

## ⚠️ Точность и калибровка

Логика **ДВС** (Япония/Корея/Китай) сверена с исходной таблицей и сходится до рублей —
мелкие отличия связаны только с курсами, которые вы задаёте в настройках.

Расчёт **электрокаров** (СТП физлица: пошлина 15% + акциз + НДС 22%) сверен с официальным
калькулятором tks.ru на данных **2026 года** и сходится до рубля. Акциз — по НК РФ ст.193
(ставка за 0.75 кВт), утильсбор — по таблице `utilEv`, таможенный сбор — Пост. 1637/1638.
При изменении законодательства правьте `exciseEv`, `customsFee`, `evVatPercent` в `js/data.js`.

## Источники ставок (актуализируйте при изменении законодательства)

- Таблицы пошлин/утиля/акциза перенесены из вашей Google-таблицы.
- Базовая ставка утильсбора — 20 000 ₽; коэффициенты — в `js/data.js`.
- Курсы ЦБ — `https://www.cbr-xml-daily.ru/daily_json.js`.
